# 复核与模板写入的切换竞态

状态：Mac 离线 Web 构建和 Playwright 模拟业务 API 回归通过；FE-047 仍有其他异步场景，四类真实样本和麒麟/NVIDIA 现场验收未做。

复核工作台现有 `contextVersion` 保护会把写入固定到操作发起时的运行或解析修订，切换文档后不把旧请求的结果、错误或后续刷新写到新工作台。本轮将浏览器延迟回归从字段决定扩展到问题处理、成果确认、冻结证据与重新生成字段候选；五类请求均在 A 文档发起，等待中切换到 B，释放响应后仍留在 B，且不会重新读取 B 的运行。服务端已接受的 A 写入并未被描述为取消。

模板管理发现并修复另一处竞态：保存新版本时仍可点选另一模板，旧成功回调原先会强行重新选择刚保存的模板；停用旧回调也会在新选择上显示过时的成功/失败文案。现在对模板选择维护视图版本，写入完成后仍刷新模板元数据，但仅在用户未改变选择时更新当前模板和提示。

验证：`cd business-web && pnpm test && pnpm build` 为 10/10、8 个离线资产。静态离线页面配模拟 API 的 Playwright `review_race_browser.py` 覆盖上述五类延迟写入；`template_write_race_browser.py` 覆盖延迟升版与停用期间切换到内置模板；既有 `template_browser.py` 创建、升版、停用正常流程通过。没有真实服务、模型或目标机运行证据。

剩余：任务重试、上传与其他异步导航/反馈仍待检查。不可仅凭这些模拟场景宣布 FE-047 或 P4 整阶段完成。
