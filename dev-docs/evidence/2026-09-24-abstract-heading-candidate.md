# 摘要章节候选（2026-09-24）

发现：MinerU 4.0 本地 Doclib 的原生 HTML Flash 解析会输出独立的 `## 摘要` 标题及后续段落。原有“摘要：值”单行规则漏掉这种常见形态；真实合同测试先失败并记录了实际页 Markdown。

实现：仅对冻结模板含 `abstract` 文本字段、且全扫描页无显式摘要标签的运行，检查历史修订第一页的精确 `摘要`/`Abstract` Markdown 标题。标题后须有空行和一个纯文本段落；遇到新标题、HTML 锚点、图片、列表、表格或引用则不猜值。候选保留整段原文（最多 2000 字），通过该修订历史 parse ID 冻结页证据，存为 `section_heading`，保持机器未确认。显式标签优先；既不把模型结构预览当证据，也不生成置信分数。Web 对新方法显示“摘要章节标题”。

业务 SQLite 与离线状态备份校验升至 schema 12；旧 schema 11 原型库不隐式迁移或删除。模型仍宿主外置，Web/Skill 仍共用无登录、用户、角色和权限管理的开放业务 API。

验证：定向字段提取、当前数据库、备份和真实本地 Doclib HTML 套件 47 项通过；完整 Mac 业务 312 项通过、2 项按现有条件跳过、2 个依赖警告。Web Node 13 项通过、离线构建 8 个资源、离线 Chromium 24 项回归通过；Ruff lint、feature-list JSON 与 diff 检查通过。真实 HTML 只覆盖 Flash/CPU，不能证明 PDF/图片模型摘要质量、四类业务准确率或隔离麒麟/NVIDIA 运行。
