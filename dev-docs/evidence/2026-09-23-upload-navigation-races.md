# 上传、重试与异步导航竞态

日期：2026-09-23。范围：开放业务 Web 的 FE-047 增量；不是整项 FE-047 或 P4 的完成声明。

- 多文件上传开始时冻结服务能力、模板和档位；上传期间禁用文件、模板和档位控件。上传完成仍刷新列表，但用户期间改变的页码或文档选择不会被旧批次重置。
- 解析任务重试的旧响应仍允许刷新任务列表；若用户已选另一文档，旧重试的成功或失败提示不再覆盖当前工作台。
- Skill 证据深链和审计记录的延迟读取，在新证据链接或手动文档选择之后失效；异步返回不得强行导航回旧文档或显示过期错误。原有正常深链和审计运行定位仍可用。
- 无用户、登录、角色、令牌或权限管理。人工复核、确认是内容流程状态；审计入口来源不代表个人身份。开放 API 的可达范围仍由物理隔离和内网部署限定。

验证：`pnpm test` 10/10；`pnpm build` 生成 8 个离线资源；Playwright `upload_retry_race_browser.py`、`navigation_race_browser.py`、`evidence_link_browser.py` 和 `audit_browser.py` 在本机静态包、模拟业务 API 下通过。原审计浏览器测试补充了原文检查响应，避免测试自身悬挂。新增/修改的浏览器测试通过 Ruff 检查，`git diff --check` 通过。

限制：模拟响应只验证浏览器时序和 UI 行为，不证明真实样本文档的解析质量，也不替代麒麟 x86_64/NVIDIA 完全离线环境验收。FE-047 的其他异步场景及 FE-046 键盘可访问性仍需继续检查。
