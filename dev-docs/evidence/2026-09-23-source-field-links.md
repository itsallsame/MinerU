# 原文页与字段双向联动验证

范围：FE-031 的可验证页级联动，不新增用户/权限体系，也不改模型侧。

实现：PDF 原文面板支持显式输入页码并打开该页；单页图片有“查找此图的关联字段”入口。复核工作台按**当前解析修订**的页码筛选已冻结证据，并根据当前提取运行列出候选/最新复核决定的字段关联。点击字段先核验绑定证据，再聚焦字段卡；字段侧可打开冻结片段，且仅当当前 Doclib 定位核验为 `current_match` 时尝试返回 PDF 页或原图。修订/运行正在加载或失败时不把空关联当作“没有字段”。证据深链也同步页级索引。

验证：`pnpm --dir business-web test` 10 项通过，`pnpm --dir business-web build` 生成 8 个离线资源。Playwright 对构建产物验证 PDF 第 2 页无冻结证据提示、切回第 1 页反查机器候选字段、证据与字段复核流程、图片单页反查与返回原图、390px 窄屏，以及证据深链正确文档/修订且无写请求。浏览器测试中第一次失败是新增按钮名造成 Playwright 非精确匹配；修正测试选择器后通过。

边界：内嵌 PDF 查看器不回传内部滚动页码或用户文字选择；页码来自显式输入或证据快照。没有声称 PDF 文字/图像 bbox 的像素级覆盖。Office 等不可内联预览的原件继续通过下载和冻结证据工作台复查。Mac 合成记录浏览器验证不代替四类真实样本与麒麟目标机验收。
