# P3 文档模板版本绑定（2026-09-23）

## 业务行为

- `POST /api/business/documents` 可选表单项 `template_code`；未选模板时 `template_code/template_version` 均为空，不做未经验证的自动分类。
- 选中模板时，在同一个业务库事务中读取启用模板当前版本、创建文档和初始解析任务，冻结版本号。后续模板修改和停用不改变文档已绑定版本。
- 未知或已停用模板返回 422，已上传但尚未登记的文件由业务工作流清理，不提交 Doclib。成功响应和文档详情显示模板代码/版本，不暴露用户身份或内部路径。
- SQLite schema 3；旧原型 schema 1/2 启动时拒绝，不迁移也不删除，避免误把开发库当作生产兼容数据。默认模板初始化与 schema 建立在同一事务，避免崩溃后出现“版本正确但默认模板缺失”的库。
