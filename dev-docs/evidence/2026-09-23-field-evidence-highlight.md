# 字段—冻结证据高亮验证

范围：FE-028。业务复核 UI 内字段候选/已复核决定到冻结证据片段的逐字高亮及反向关联，不增加用户或权限管理。

实现：字段卡可打开其 `evidence_id` 指向的服务端冻结证据。片段中字段值出现时以文本节点标记，最多高亮 20 处；值不逐字出现时显示明确提示，不尝试模糊猜测坐标。证据视图可列出此运行中引用同一证据的候选/最新复核字段，点击定位字段卡。当前 Doclib 内容核验不是 `current_match` 时，不提供 PDF 当前原文页跳转。

验证：`pnpm --dir business-web test` 10 项通过，`pnpm --dir business-web build` 生成 8 个离线资源；Playwright 对构建产物验证候选高亮、已复核字段高亮、证据反查字段、规范化值不匹配时无虚假 `<mark>`、变化的当前定位不允许页跳转及原复核流程，窄屏无横向溢出。第一次浏览器命令的自动审批等待超时，原命令重试通过；未把审批超时当作产品失败。

边界：高亮的是不可变**证据片段**，不是内嵌 PDF 查看器中的原生文字坐标或视觉 bbox。FE-031 的原文侧双向联动仍开放；四类真实样本和麒麟现场尚未验收。
