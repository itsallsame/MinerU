# 四类样本评估：历史目录分页进展边界

日期：2026-09-24。范围：真实样本验收工具的可选 `expected_headings` 读取；本次只使用 Mac 合成响应，无真实四类原文或麒麟运行。

发现：工具原先只累计服务返回的 `scanned_pages`，但 Python 布尔值也是整数；负数可抵消已扫页数，连续 `0` 页带下一页也不增加累计值。异常服务响应因此可能让完整目录评估继续请求，不能可靠地以 1000 页上限终止。

修正：拒绝布尔/负数页数、布尔/非正/倒退的下一页；若 `scanned_pages=0`，只允许终止页，不允许继续分页。另设置独立的最多 1000 次请求上限，防止页数计数与响应行为不一致时无限续读。任何这些异常均以评估错误退出，不发布总报告；正常空终止页仍允许。

定向 `tests/business/test_sample_evaluation.py` 为 18 passed，包含 5 个异常分页参数与请求上限回归；Ruff lint 通过。完整业务套件结果记于本轮进度记录。此处仅证明评估器面对合成响应的失败边界，不证明真实文档标题准确率、模型加载或麒麟/NVIDIA 性能。
