# 历史解析修订逐页差异验证

范围：FE-026。仅比较同一业务文档的两次历史机器解析修订；不做旧 3.4/V1 兼容，不引入用户或权限层。

实现：业务 API 按两个修订各自的页—批次映射调用 Doclib 历史读取，逐页比较完整解析文本；输出 `same/changed/only_left/only_right`、页定位器、每次最多 25 页及续扫页号。Web 在复核工作台显示机器解析差异，并可按需读取两版全文；窄屏上下排列。任何需比较页发生截断或历史内容不可信，整次请求失败，不返回部分结论。

验证：模拟 Doclib 契约测试覆盖实际 parse ID 路由、同文约束、跨页缺失、25 页续扫、截断失败与 API 状态/不泄露内部 ID；真实 Doclib HTML 同源两批次旧/新不同内容测试通过；Web 9 项单测、8 资源离线构建通过，Playwright 对构建产物验证差异、两版读取及原复核流程；完整业务测试 122 项通过（2 个依赖弃用警告）。

限制：比较的是整页机器文本的逐字相等性，不是字符级 diff，也不含原生结构树、图像、bbox、字段候选、冻结证据或人工成果；两版文本相同不能推导所有结构或业务结论相同。真实四类标注样本与麒麟目标机仍未验收。
