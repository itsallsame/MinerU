# 历史解析原生块树验证（Mac）

日期：2026-09-23。范围：MinerU 4.0.6 fork 的持久 Middle JSON → Doclib 公共接口 → 开放业务 API → Web/自有 Skill。

## 契约

- Doclib 返回模型实际存在的父子块节点、模型类型、层级路径、可用 bbox/标题级别及最多 200 字符安全文本预览；视觉载荷、资源路径与 URL 不序列化。每页超过 500 顶层块、2000 总节点或 16 层则报错，不静默丢节点。
- 历史解析批次绑定不变。业务层递归核验身份、页面、路径、定位器与子节点顶层锚点；业务响应不含 parse ID 和内部路径。
- 子节点并无官方独立定位器。它们继承顶层块定位器；Web 只为顶层块提供“读取此块”，并标注子节点是父块定位。机器结果仍未人工确认，不作为冻结证据。

## 运行验证

- 真实本地 Doclib 先解析 HTML，再将该批次持久 Middle JSON 注入合法 list→text 嵌套模型；公共接口返回 `[0]`/`[0,0]` 两级路径、子节点文字预览和同一顶层块锚点。这个测试验证读取/序列化契约，不宣称模型可自动把所有 HTML 列表识别为列表。
- Mock 契约验证业务历史页批次选择、递归节点、伪造子节点锚点拒绝、Web/Skill 同业务 API。Playwright 在实际构建的 Web bundle 上验证嵌套节点显示、父块定位提示与既有人工复核流程。
- 业务测试 112 项通过（2 条依赖弃用警告）；相关上游 Doclib 测试 41 项通过；Web 9 项测试通过，离线构建 8 个资产；Ruff 通过。

## 边界与后续

FE-023 完成的是**现有模型 schema 中的原生解析块树展示**，不扩写模型不存在的表格单元格层级，也不提供虚假的子节点精确定位。FE-018 页/块证据搜索列表、四类人工标注真实样本以及隔离麒麟 x86_64 + NVIDIA 目标机验收仍未完成。Mac 结果不能当作生产验收。
