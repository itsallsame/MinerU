# Web 服务断线与恢复（FE-047 部分）

本轮沿用“开放系统、无登录／用户／角色／权限管理”前提。连接错误恢复只依赖重新读取开放业务 API，不引入令牌、身份或访问控制。

## 已实现

- 页面初次加载或用户点击“刷新列表”时，重新读取服务能力、模板及文档列表。能力读取失败时暂停上传；模板读取失败时不沿用旧模板列表，并给出错误提示。
- 文档列表读取失败时不保留旧的任务徽标、文档数量和详情／复核工作台，避免旧状态被误认为当前状态；上传和分页暂停，提供“重新连接并刷新”入口。
- 服务恢复后，重新获取能力、模板和当前文档列表，恢复上传和列表交互。普通筛选、分页和轮询仍按各自请求刷新。
- 文档详情读取修订列表失败时显示错误和就地重试；重复选择同一文档时以最后一次选择请求为准，旧响应不能覆盖新响应。
- 复核工作台分别处理解析修订元数据和提取运行读取失败：显式失败提示与重试入口；修订数据不可用时不开放字段候选生成，运行数据不可用时不再无限显示“正在读取”。
