# 任务操作异步刷新后的键盘焦点

日期：2026-09-25。范围：本地 Mac 离线 Web 合成数据回归；未覆盖真实文档、屏幕阅读器或麒麟目标浏览器。

## 问题与处理

取消请求结果不明时，页面刷新后允许先以 GET 核对任务。键盘激活“核对取消状态”后，任务列表刷新重绘按钮；原焦点随旧 DOM 消失。新增浏览器断言在修改前失败（`cancellation check lost keyboard focus`）。

任务取消、任务重试及原请求键核对期间，现在保留可聚焦按钮，使用 `aria-disabled` 告知忙碌状态，并以本地 busy 标记拦截重复触发。详情重绘时，焦点跟随同一任务操作；若该操作因任务进入终态而消失，焦点落到带可见轮廓的“处理状态”区域。仅当重绘前焦点仍在该操作上时才续接，不抢占用户后来移走的焦点。
