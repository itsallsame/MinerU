# Web 候选来源呈现（2026-09-24）

背景：MinerU 4.0 原生 `doc_title` 已可形成带冻结证据的未确认候选，但复核页此前仅显示字段值和操作，操作者看不出是显式“字段标签：值”规则还是原生标题块。

复核页现在从同一开放业务 API 的 `candidate.method` 显示“显式字段标签”或“MinerU 原生标题块”，两者都标“未确认”。未知方法显示“来源未识别”，不把原始方法字符串作为可信来源解释。确认仍需人明确接受候选或填入人工决定，来源标签不会改变后端决定规则。Web 与自有 Skill 仍消费同一 API，没有登录、用户、角色或权限管理。

验证：Web Node 单测 13 项通过，离线 Web 构建生成 8 个资源；24 项离线 Chromium 回归通过，复核页断言可见显式来源标签且既有证据、人工决定、问题门禁与成果版本流程未退化。没有真实四类标注数据、目标麒麟浏览器或 NVIDIA 模型质量证据。
