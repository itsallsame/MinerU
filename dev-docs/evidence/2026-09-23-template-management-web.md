# 开放系统模板管理 Web 验证（Mac）

日期：2026-09-23。基线为 MinerU 4.0.6 fork master。此项完成 P4 的 FE-041/FE-042 页面能力，不代表整个 P4 或生产环境验收。

## 实现契约

- Web 在同一个业务工作台内列出模板，内置四类模板只读；自定义模板可创建和保存新版本，不能原地修改已存在的版本。
- 字段配置包含唯一代码、显示名称、`text/date/list` 类型、必填标记和顺序。前端先校验，服务端仍执行最终校验。
- 停用自定义模板需要明确确认；停用只影响后续上传选择，旧文档与旧版本保留。没有登录、用户、角色、审批或所有者逻辑。
- 所有调用经过 `/api/business/templates` 同源业务 API；上传与筛选选项在变更后更新。

## 验证结果

- `pnpm --dir business-web test`：9 项通过；`pnpm --dir business-web build`：8 个离线资产构建通过。
- Playwright 对实际构建包与模拟业务 API 验证：内置模板只读、自定义模板创建、字段上移后的提交顺序、追加 v2、停用及上传选项禁用；390px 宽度无水平溢出。重新构建后，模板、业务检索、证据深链、复核四条浏览器流程均通过。
- 现有业务模板 API/存储契约测试 5 项通过，证明旧版本可读、已绑定文档版本冻结、内置保护与停用行为。
- `dev-docs/feature-list.json` 的 FE-041、FE-042 已标记通过，完成数 46/241；其他 P4 项及目标机验证仍开放。

## 限制

浏览器流程使用模拟 API，未以真实业务样本验证模板字段提取质量。字段规则仅是现有初版标签匹配，不含复杂结构编辑、规范化和置信评分。麒麟 x86_64/NVIDIA 完全离线部署尚未验证。
