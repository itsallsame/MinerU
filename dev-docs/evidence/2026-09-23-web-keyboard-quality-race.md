# 业务 Web 键盘焦点与统计请求竞态

状态：Mac 上的前端单测、离线构建与 Playwright 合成数据回归通过；FE-046、FE-047 仍未整体完成，四类真实文档和麒麟浏览器现场验收未做。

文档列表选中按钮时会重绘整个列表，原按钮被删除，键盘焦点丢失。现在给文档卡片稳定业务 ID、当前项语义，并在重绘后仅当原焦点位于该卡片且新列表仍有同一 ID 时恢复焦点；不把焦点转移到其他文档。补齐 `textarea`、`summary` 和可程序聚焦复核字段卡片的可见焦点轮廓。

质量统计允许快速连续刷新。以前较早请求可在较新请求后返回并覆盖界面；现在用递增请求序号丢弃过时成功或失败结果，关闭面板也令在途请求失效。没有添加登录、用户、角色或权限逻辑。

验证：`cd business-web && pnpm test && pnpm build` 为 10/10 单测、8 个离线资产；用 Python 标准静态服务器提供构建包，`python3 business-web/tests/keyboard_focus_browser.py http://127.0.0.1:18088` 和 `python3 business-web/tests/quality_browser.py http://127.0.0.1:18088` 均通过。前者以 Enter 选中文档并确认重绘后同一按钮仍有焦点和可见轮廓；后者延迟旧响应，确认新统计不被覆盖，并检查窄屏布局。既有 `recovery_browser.py` 和 `review_browser.py` 也通过。静态服务器仅用于页面，业务 API 均为测试模拟，不代表真实服务或目标机。

剩余：复核工作台其他动态控件的焦点保持、完整键盘遍历与屏幕阅读器检查，以及异步写操作切换场景仍待验证。
