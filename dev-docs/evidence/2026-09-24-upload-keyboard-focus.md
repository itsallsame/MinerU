# FE-046 增量：上传未知结果的键盘焦点

Mac Chromium 回归先复现：键盘提交批量上传后，提交按钮在请求期间被禁用，焦点落到页面空白而非反馈；用户聚焦“使用同一请求键重试”并再次得到未知结果时，该按钮被重建，旧焦点随之丢失。第二种情况还存在先尝试聚焦、后解除按钮禁用的时序错误。

修复：上传批次结束且用户原本聚焦提交按钮、期间没有主动移到其他控件时，把焦点放到带可见轮廓的反馈区；下一次 Tab 进入首个重试按钮。键盘触发重试后，若仍是未知结果，在替换按钮重新启用后恢复其焦点；若已受理或确定失败，焦点放到有可见轮廓的当前结果项。鼠标操作或用户主动移动焦点时不强行夺回。

验证：新增断言在修复前明确失败于批次结果焦点；修复过程又复现并纠正了“新按钮尚未启用就聚焦”的失败。最终 Web 11 个 Node 测试、8 个离线构建资产和 22 个 Chromium 场景通过；浏览器断言覆盖 Enter 提交、反馈轮廓、Tab 到首个重试、再次未知后焦点恢复、成功后结果焦点与轮廓。`FE-046` 仍保持未完成：尚未完成全页面逐项键盘遍历、真实屏幕阅读器检查和麒麟目标浏览器验收。系统仍无用户或权限管理。
