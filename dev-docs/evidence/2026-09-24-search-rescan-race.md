# 历史块搜索挂起后的重新扫描与旧响应隔离

日期：2026-09-24。源码基线：fork `master` 的 `38840d55`，改动位于 `business-web/src/app.js` 与浏览器回归脚本。环境：Mac、本仓库离线 Web 构建、预装 Playwright Chromium；API 响应由浏览器回归脚本模拟。对应 FE-047 的一个局部恢复场景，不代表完整 FE-047 或麒麟验收。

## 问题与修正

检索结果的块级扫描按最多 25 页继续读取。旧界面在扫描请求未完成时禁用“查找块级候选依据”，请求长期挂起时无法重新发起。现在允许用户在同一检索结果上重新扫描，并为每次完整扫描分配代次。续页和重试沿用所属代次；返回时只有当前检索请求且当前扫描代次可以写入候选块、错误和续页按钮。重新扫描会清掉旧结果，较早的请求即使后来完成也不能混入新一轮结果。

这不取消服务器上的已发出请求，也不假装已停止 Doclib 计算；只是保证 Web 展示和操作响应属于当前扫描。没有引入用户或权限管理。
