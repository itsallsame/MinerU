# 模板管理键盘焦点与提示语义

日期：2026-09-23。范围：FE-046 的模板管理增量，尚非整页或屏幕阅读器验收。

发现：键盘按 Enter 选择已有模板或进入“新增自定义模板”时，模板区域重绘会移除被激活的按钮，焦点可能落到页面根部。保存和错误文案没有明确的状态/警报语义。

处理：选择已有模板后将焦点移到重绘后的同一模板按钮；进入新建时将焦点移到模板代码输入框。错误文案使用 `role=alert`，保存成功文案使用 `role=status`。该页面仍是开放系统，没有用户、所有者或审批权限。

验证：`cd business-web && pnpm test && pnpm build` 通过 10 个单测并生成 8 个离线资源；Playwright `template_browser.py` 用 Enter 键验证焦点连续性、可见轮廓、成功状态语义和既有创建/升版/停用流程；`template_write_race_browser.py` 验证延迟写入不覆盖新的模板选择。浏览器使用模拟业务 API。

余项：实际屏幕阅读器朗读、完整 Tab/Shift+Tab 遍历以及其余工作台路径尚未验收，FE-046 保持未完成。
