日期：2026-09-25。目标：在完全离线的代码增量导入前，独立确认 Git 包不夹带模型权重对象，而不是只依赖准备机创建脚本的检查。

发现：`create` 已拒绝本次 Git 增量中出现过的模型权重，即使随后删除；但 `verify --target-repo` 原先只核对包哈希、引用和目标旧提交。一个由其他工具制作、内部哈希自洽的包可包含临时权重对象，并在目标机 `fetch` 时导入对象库，违背“只传必要代码、模型独立”的交付边界。
