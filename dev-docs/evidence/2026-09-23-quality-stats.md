# 质量与处理统计页验证

范围：FE-043。业务 Web/API、开放系统；无用户、角色、权限或操作人字段。

实现：`GET /api/business/quality-stats` 在 SQLite 只读事务中聚合 11 个流程记录计数；Web 折叠面板展开才请求，支持手动更新。计数单位分别是业务文档、解析任务、修订、提取运行、开放阻断问题、已确认的不同提取运行和成果版本。同字节不同业务文档不合并，历史任务/运行/版本不去重为“当前状态”。不计算未经真实标注验证的准确率。

验证：定向后端测试 12 项通过；完整业务测试 119 项通过（2 个依赖弃用警告）；Web 单测 9 项通过，离线构建 8 个资源；Playwright 对构建后页面验证惰性加载、11 项计数、手动刷新和 390px 窄屏无横向溢出。浏览器使用模拟 API 响应，不能代替真实样本质量验收。首次全量测试因沙箱禁止本机监听而失败，获本机临时监听权限后原样重跑通过；麒麟现场验证仍待进行。
