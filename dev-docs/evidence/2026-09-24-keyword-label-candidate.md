# 关键词显式标签候选（2026-09-24）

范围：P3 `BE-038` 的可追溯原型。原有规则只识别模板中文标签及冒号放在 Markdown 加粗标记外的形式；英文论文的 `Keywords: value` 和 `**关键词：** value` 容易漏提。现在对冻结模板中代码为 `keywords`、标签为“关键词”的字段增加精确英文 `Keywords` 别名，并让显式标签规则兼容冒号在加粗标记内或外。没有独立标签和值的章节标题、行内正文仍不猜测。

候选保留完整原文字符串及原有分隔符，不将 `;`、`、` 或逗号拆成多个未经证实的字段值。每项仍通过历史 parse ID 所在页冻结证据，存为 `label_rule`，由 Web/API/自有 Skill 显示为机器未确认；提取不自动完成复核或成果确认。未新增登录、用户、角色或权限体系。此改动不改变业务数据库 schema、模型目录或代码镜像边界。

验证环境：Mac 开发机、本 fork 当前工作树、Python 3.13，本地 Doclib HTML Flash/CPU。定向字段提取覆盖中英文标签、冒号位于加粗标记内外、非标签正文与无值章节标题；真实 Doclib HTML 联调通过，解析后的英文关键词候选值为 `document parsing; evidence`，冻结证据片段包含该值。最终工作树的完整 `tests/business` 为 325 通过、2 跳过、2 个第三方依赖警告；Ruff lint、feature-list JSON 和 `git diff --check` 通过。代码审查核对了只对精确关键词字段启用英文别名、原文子串与同修订证据约束、未确认状态、无 schema 和鉴权变化。

限制：这是 Flash/HTML 规则和合成内容验证，不是公文、论文、研究报告、报纸四类脱敏真实标注样本的准确率、PDF/VLM 或麒麟 x86_64+NVIDIA 的验收；`list` 字段标准化也未完成。`BE-038` 和 P3/P6 仍为未完成。回退仅需还原本次源码提交；没有数据迁移。
