# 全局审计记录页验证

范围：FE-044。保留完全开放的业务 API；不建立用户、角色、权限或个人操作人字段。

实现：追加式 `audit_events` 通过业务文档与修订关联全局展示；只读 `GET /api/business/audit` 按内部插入序号倒排，以事件 ID 作为 `before` 游标，限制每页 1–100 条。游标分页避免新事件导致旧页重复或跳项。Web 按需加载、刷新、加载更早记录，展示动作、来源、变更值和原因；可以跳至对应的业务修订/提取运行。前端对文档名与字段值使用文本节点，不执行内容内的 HTML。

边界：`web/skill/api` 是调用入口，不是自然人身份。现有审计只记录字段决定、问题处理、成果确认；不声称覆盖上传、解析、读取，也不是抗管理员篡改的签名日志。页面只在业务内网/物理隔离部署范围内开放，系统本身没有访问授权层。

验证：后端契约测试覆盖游标稳定、动作顺序、文档关联、无身份字段、无效游标与限额；完整业务套件 120 项通过（2 个依赖弃用警告）；Web 9 项单测、8 个离线静态资源构建通过；Playwright 对构建产物验证按需加载、分页、恶意 HTML 文本不执行、回到特定提取运行与 390px 窄屏。目标麒麟环境仍待验证。
