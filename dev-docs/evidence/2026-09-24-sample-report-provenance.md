# 四类样本报告的解析修订来源记录

日期：2026-09-24。范围：只读四类样本评估器；真实样本和目标麒麟环境未验收。

旧评估报告只保留用户输入的环境文字及修订 ID；同一报告混用不同解析档位或 MinerU 版本时无法直接从脱敏报告发现。现在评估每个 case 时读取业务 API 的历史解析修订，要求 `document_id` 与修订 ID 匹配、修订 `short_id` 等于原文 SHA-256 的前 12 位、`tier` 是四档之一、`producer_version` 非空。报告在 case 级记录实际 `tier`/`producer_version`，总报告列出去重后的档位和生产者版本；来源不匹配则整份报告失败，不发布部分分数。

定向测试 `tests/business/test_sample_evaluation.py` 为 11 passed：用合成四类样本与真实 FastAPI 测试客户端验证服务端字段，覆盖错误修订短哈希拒绝和混用两种档位/生产者版本的显式汇总。完整 `tests/business` 为 346 passed、2 skipped、2 个第三方依赖警告；Ruff lint 和差异检查通过。该记录只能证明业务库所存的修订元数据，**不证明**当前运行镜像的源码提交、模型权重哈希或 NVIDIA 推理链。生产报告必须另与所选 `release.json`、制品核验报告、运行态报告和真实样本验收记录一同归档；机器候选分数不代替人工确认质量。
